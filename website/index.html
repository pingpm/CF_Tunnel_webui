基于 Cloudflare Tunnel 的新一代管理面板。无需配置，一键安装，让你的本地服务瞬间在公网优雅上线。

立即开始使用 查看文档
curl -sSL https://raw.githubusercontent.com/.../install.sh | bash

极速安装

自适应 Linux 与 Windows 环境。智能检测 Node.js 并在缺失时自动补全，秒级进入工作状态。

专业界面

拒绝过时的 AI 审美。极致简约的 UI 设计，支持中英双语与响应式布局，无论手机还是电脑皆可随心掌控。

零配置上线

无需 Cloudflare 账号，无需购买域名。利用 TryCloudflare 快速通道，瞬间获取专属公网加密连接。
